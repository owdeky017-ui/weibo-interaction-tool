微博互动查询器 WeiboInteractionQuery · 使用说明
=============================================

（这是源码目录里的说明草稿。真正随包分发的那一份由 build.py 生成，
   打包后的目录里会有一份对应的 使用说明.txt，以那份为准。）

【这是什么】
提取「你（当前登录账号）」与另一个微博用户之间的互动记录
（转发 / 评论 / 评论回复 / 点赞），一键导出 Excel 表格 + HTML 日志，
HTML 日志会自动在浏览器打开。

【用户A 是怎么确定的】
本版「用户A」固定为**当前扫码登录的微博账号**，不可手填。
你只需要填写用户B（想查谁和「你」的互动）。

【使用方法】
1. 双击「WeiboInteractionQuery.exe」
2. 点「扫码登录微博」——用手机微博 App 扫屏幕上的二维码并确认
   （只需登录一次，下次打开自动登录）
3. 登录成功后，「用户A」会自动填入你的昵称和 uid（只读）
4. 填写 用户B（支持：昵称 / 微博主页链接 / 纯数字 uid）
5. 选时间范围（最近 7/30/90/180/365 天或自定义）、互动类型、抓取速度
6. 点「开始抓取」，等待下方日志滚动完成
7. 完成后自动打开 HTML 日志，Excel/CSV 在程序同目录的 data\output 文件夹里

【速度怎么选】
- 慢（最稳）：请求间隔 1.2 秒，几乎不会触发风控，适合大范围抓取
- 中：0.6 秒，日常推荐
- 快（易风控）：0.25 秒，小范围试试可以，大范围容易触发微博限制

【常见问题】
- 提示「触发风控」：程序会自动等待 180 秒后继续，不用管它；
  如果频繁触发，改用「慢」速度重跑。
- 提示「登录态已失效」：回到登录区重新扫码。
  注意：重新登录必须用**同一个账号**——用户A 就是登录账号，
  换了账号程序会中止并提示，避免把两个人的记录混在一起。
- 结果在哪：程序同目录 \data\output\ 里，
  文件名形如 微博互动_你的昵称_对方昵称_时间戳.xlsx / .csv / .html
- 点赞数量可能不全：微博网页版点赞接口经常被限制，程序会自动改用
  移动端接口；若仍失败会在日志里提示，其余类型不受影响。
- 评论里的楼中楼回复（评论下的回复）也会抓取，并显示「回复的是哪条评论」。

【关于账号】
程序使用你自己的微博账号登录去读取公开数据，仅供个人查看互动记录使用，
请勿用于商业用途或骚扰他人。

【打包信息】
